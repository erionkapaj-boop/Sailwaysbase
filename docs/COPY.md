# Κανόνες για τα κείμενα της πλατφόρμας

Οδηγία του ιδιοκτήτη. Ισχύει για κάθε κείμενο που βλέπει πελάτης ή
επαγγελματίας: σελίδες, ειδοποιήσεις, email, μηνύματα σφάλματος.

1. **Ενημέρωση, όχι δικαιολογία.** Λέμε τι ισχύει και τι μπορεί να κάνει ο
   χρήστης. Δεν εξηγούμε γιατί το αποφασίσαμε, δεν απολογούμαστε, δεν
   καθησυχάζουμε («δεν έχεις χρεωθεί τίποτα», «για την ασφάλειά σου», «αν
   νομίζεις ότι είναι λάθος»).
2. **Όχι υποσχέσεις χρόνου** που δεν ελέγχουμε («συνήθως μέσα στην ημέρα»).
3. **Όχι ιδέες για παράκαμψη.** Δεν γράφουμε τι απαγορεύεται πάνω σε
   φωτογραφίες ή σημειώσεις (π.χ. «χωρίς τηλέφωνο, email») — ο έλεγχος γίνεται
   σιωπηλά.
4. **Όχι λόγοι στον χρήστη** για ενέργειες της διαχείρισης (αφαίρεση
   φωτογραφίας κ.λπ.). Ο λόγος που γράφει ο διαχειριστής μένει εσωτερικός.
5. Σύντομα. Μία πρόταση όπου φτάνει μία.

Οι Όροι χρήσης και η Πολιτική απορρήτου είναι νομικά κείμενα και εξηγούν όσο
χρειάζεται ο νόμος.
