## Κανόνες (ισχύουν για κάθε νέα οθόνη — βλ. docs/DESIGN.md «Πλοήγηση εφαρμογής»)
1. Ένα εικονίδιο ανά έννοια, παντού το ίδιο (`components/Icon.js`).
2. Σταθερός σκελετός: πάνω ← / λογότυπο, κάτω μπάρα, μία κύρια ενέργεια κάτω.
3. Κατάσταση με σήμα (χρώμα + εικονίδιο + μία λέξη).
4. Λιγότερο κείμενο: τίτλος 1–3 λέξεις, μία γραμμή από κάτω, λεπτομέρεια πίσω από ⓘ.
